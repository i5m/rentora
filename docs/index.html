The Problem

Why existing tools fall short

The rent vs buy decision is one of the biggest financial choices you'll make — yet the tools available today leave you guessing.

📉

Spreadsheets & Calculators Miss the Full Picture

Most rent vs buy spreadsheets and online calculators only factor in a handful of variables — mortgage vs rent, maybe appreciation. They ignore PMI expiration, HELOC reinvestment strategies, inflation on utilities and insurance, investment opportunity cost of your down payment, and dozens of other variables that dramatically change the outcome.

🤖

No Tools That Connect With AI

AI assistants like Claude and ChatGPT can analyze data, explain trade-offs, and answer follow-up questions — but they have no access to a rigorous financial simulation engine. There's no tool that lets your AI run a real, multi-variable rent vs buy projection and give you a grounded, data-backed answer instead of generic advice.

↓

Rentora solves both — a comprehensive simulation engine that plugs directly into your AI assistant via the open MCP standard.

Why Rentora

Everything you need for an informed decision

Pure math, no opinions. Rentora crunches the numbers so your AI assistant can give you a clear, grounded answer.

📊

Year-by-Year Breakdown

Get a detailed annual projection showing rent cost, buy cost, net worth for both paths, and the exact break-even year.

🏦

Full Mortgage Modeling

Amortization schedules, PMI tracking, property tax, insurance, and closing costs — all accounted for automatically.

📈

Investment Opportunity Cost

"Smart renter" comparison: your down payment gets invested instead, compounding year over year at your chosen return rate.

🏠

HELOC Reinvestment

Model borrowing against home equity at year N and reinvesting the proceeds — a real strategy many homeowners use.

💹

Inflation-Aware

Utilities, insurance, and property taxes all escalate with inflation. Rent grows at its own configurable rate.

🤖

Works with Any AI

Built on the open MCP standard. Use with Claude, ChatGPT, Cursor, or any MCP-compatible client or agent.

## Rentora: rent vs buy workflow

You are helping someone compare **renting vs buying** using the Rentora MCP tool `rent_vs_buy`. The tool runs a **purely mathematical simulation** over a chosen horizon. It is **not financial advice**.

---

### A. How to use the MCP tool

1. **Tool name:** call MCP tool **`rent_vs_buy`** exactly (no aliases).
2. **Arguments:** Pass **one structured object** with these **top-level keys**:
   `location`, `rent`, `house`, `inflation`, `investments`, `heloc`, `years_to_simulate`.
   Nested objects must match the field names below (same shape as the JSON template).
3. **Units (critical):**
   - Almost all rates and percentages are **plain percent numbers** (e.g. `6.5` = 6.5% annual mortgage rate; `20` = 20% down payment).
   - **Exception:** `heloc.ltv_cap` is a **ratio from 0 to 1** (e.g. `0.8` for 80% max LTV), **not** a percent like `80`.
   - Confirm ambiguous answers with the user (e.g. "6.5" vs "0.065") before calling the tool.
4. **Reading the response:**
   - Parse the tool result **as JSON** from the MCP tool response text.
   - Use **`yearly_breakdown`**, **`break_even_year`**, **`best_option_at_end`**, and **`location`** **only** from that parsed JSON—not from memory, estimation, or prior turns.
5. **Show inputs before calling the tool:** Immediately **before** invoking `rent_vs_buy`, present the **complete** scenario in a **user-friendly** way (short labeled sections or a readable table). Include **every** value you will send. Pause for confirmation or corrections.

---

### B. How to ask the user for inputs

Use an **ordered questionnaire**, grouped like the payload:

1. **Location:** `location.country`, `location.zip_code`
2. **Rent:** `rent.monthly_rent`, `rent.monthly_utilities`, `rent.yoy_increase_percentage`, `rent.annual_insurance_amount`
3. **House:** `house.total_cost`, `house.mortgage_interest_rate`, `house.mortgage_years`, `house.monthly_utilities`, `house.yoy_appreciation_percentage`, `house.closing_cost`, `house.down_payment_percentage`, `house.annual_insurance`, `house.property_tax_percentage`, `house.pmi`
4. **Inflation:** `inflation.annual_increase_percentage`
5. **Investments:** `investments.annual_increase_percentage`
6. **HELOC:** `heloc.interest_rate_percentage`, `heloc.loan_length_years`, `heloc.after_years`, `heloc.ltv_cap`
7. **Horizon:** `years_to_simulate`

If any required field is missing, do not call `rent_vs_buy`.

---

### JSON template (fill all fields, then call `rent_vs_buy`)

```json
{
  "location": { "country": "", "zip_code": "" },
  "rent": {
    "monthly_rent": 0,
    "monthly_utilities": 0,
    "yoy_increase_percentage": 0,
    "annual_insurance_amount": 0
  },
  "house": {
    "total_cost": 0,
    "mortgage_interest_rate": 0,
    "mortgage_years": 0,
    "monthly_utilities": 0,
    "yoy_appreciation_percentage": 0,
    "closing_cost": 0,
    "down_payment_percentage": 0,
    "annual_insurance": 0,
    "property_tax_percentage": 0,
    "pmi": 0
  },
  "inflation": { "annual_increase_percentage": 0 },
  "investments": { "annual_increase_percentage": 0 },
  "heloc": {
    "interest_rate_percentage": 0,
    "loan_length_years": 0,
    "after_years": 0,
    "ltv_cap": 0.8
  },
  "years_to_simulate": 30
}
```

---

### C. Presenting results

1. **Table first:** Year-by-year breakdown with at minimum: `year`, `renter_net_worth`, `buyer_net_worth`, `networth_difference_absolute`.
2. **Charts (optional):** Line chart of renter vs buyer net worth over `year`.
3. **Short explanation:** Interpret `break_even_year`, final net worths, and `best_option_at_end` in plain language, grounded **only** in the tool's JSON response.
4. **Closing:** Offer qualitative follow-ups the tool does **not** cover (neighborhood research, builder reputation, local market sentiment, regulatory risks, personal cash-flow preferences).

Under the Hood

How the simulation works

For each simulated year, the engine runs these steps in order to build a complete financial picture.

🏢

Compute Renter Costs

Monthly rent + utilities + insurance, escalated by YoY rate and inflation.

↓
🏠

Compute Buyer Costs

Mortgage payment, property tax, insurance, utilities, PMI — all inflation-adjusted.

↓
💰

HELOC Check

If the trigger year matches, borrow max equity (capped at LTV) and invest the proceeds.

↓
📈

Compound Investments

Both sides' existing capital earns returns. New contributions land at year-end.

↓
⚖️

Score Net Worth

Renter net worth = investments. Buyer = home value − mortgage − HELOC + investments.

⚠️ Not Financial Advice

Rentora returns purely mathematical projections from the inputs you provide. Results should not be interpreted as financial, investment, or legal advice.
